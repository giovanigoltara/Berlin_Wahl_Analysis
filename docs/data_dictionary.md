# Data dictionary

Generated by `src/data_dictionary.py` from `datapackage.json` (version 0.1-preliminary), which is validated against the files on every run. It describes every committed output table. In PostGIS the same columns live in the tables named in each description; districts are keyed by `uwb` throughout.

Licence of the derived tables: Open Data Commons Open Database License 1.0. Sources and their licences are listed in `docs/provenance.md`.

## `data/processed/indicators.csv`

The analysis table: one row per polling-station district (analysis.indicators in PostGIS, sql/50_indicators.sql, without geometry). Vote outcomes use postal allocation method C. Indicators are computed over the district's residential land.

Primary key: `uwb`.

| Column | Type | Unit | Definition | Source |
| --- | --- | --- | --- | --- |
| `uwb` | string |  | Polling-station district (Urnenwahlbezirk) number; the first two digits are the Bezirk. | Wahlbezirke 2026 |
| `bez` | string |  | Bezirk (borough) number, 01 to 12. | Wahlbezirke 2026 |
| `residents` | number | persons | Residents 2025 in the district, from population blocks split by area where a block crosses a district boundary. | Einwohnerdichte 2025; sql/30_dasymetric.sql |
| `residential_residents` | number | persons | Residents of blocks that count as residential land (excluding open land and infrastructure block types). | Einwohnerdichte 2025; sql/30_dasymetric.sql |
| `density_residential` | number | persons per ha | residential_residents per hectare of residential land. Empty where the district has no residential land. | sql/30_dasymetric.sql |
| `log_density_residential` | number | ln(persons per ha) | Natural logarithm of density_residential; the control variable of the Tier 1 partial correlations. | sql/50_indicators.sql |
| `lst` | number | degrees Celsius | Summer land surface temperature: area-weighted mean over the zone in satellite_zone of the per-pixel median of clear Landsat 8/9 observations, June to August 2023 to 2025. | Landsat 8/9 C2 L2; src/gee_extract.py, sql/35_satellite.sql |
| `ndvi` | number | dimensionless, -1 to 1 | Summer NDVI: area-weighted mean over the zone in satellite_zone of the per-pixel median of clear Sentinel-2 observations, June to August 2023 to 2025. | Sentinel-2 SR, Cloud Score+; src/gee_extract.py, sql/35_satellite.sql |
| `satellite_zone` | string |  | Area over which lst and ndvi were averaged: the residential land, or the whole district when residential land is missing or too small (imagery.min_residential_pixels). Values: `residential`, `district`. | sql/35_satellite.sql |
| `satellite_fallback` | boolean |  | True where satellite_zone is the whole district. | sql/35_satellite.sql |
| `access_index` | number | standard deviations | Mean over the 7 amenity categories of the z-scored ln(1 + mean nearest distance in m). 0 is the Berlin district average; higher means farther from everyday services. | OpenStreetMap; sql/50_indicators.sql |
| `population_mismatch` | boolean |  | True where the 2026 register lists more eligible voters than the 2025 population has residents, or the district has no residential land; population-weighted indicators are unreliable there. | sql/30_dasymetric.sql |
| `dist_health` | number | m | Residents-weighted mean straight-line distance from residential land to the nearest doctor, clinic, hospital or pharmacy. | OpenStreetMap; sql/40_accessibility.sql |
| `dist_kindergartens` | number | m | As dist_health, to the nearest kindergarten. | OpenStreetMap; sql/40_accessibility.sql |
| `dist_parks` | number | m | As dist_health, to the nearest park (distance to its edge). | OpenStreetMap; sql/40_accessibility.sql |
| `dist_playgrounds` | number | m | As dist_health, to the nearest public playground. | OpenStreetMap; sql/40_accessibility.sql |
| `dist_public_transport_stops` | number | m | As dist_health, to the nearest bus stop, tram stop or rail station. | OpenStreetMap; sql/40_accessibility.sql |
| `dist_schools` | number | m | As dist_health, to the nearest school. | OpenStreetMap; sql/40_accessibility.sql |
| `dist_supermarkets` | number | m | As dist_health, to the nearest supermarket. | OpenStreetMap; sql/40_accessibility.sql |
| `afd` | number | share, 0 to 1 | AfD (P05) share of valid Zweitstimmen, station plus allocated postal votes (method C). | Landeswahlleiter; sql/20_postal_allocation.sql, sql/50_indicators.sql |
| `bsw` | number | share, 0 to 1 | BSW (P24) share of valid Zweitstimmen, method C. | Landeswahlleiter; sql/20_postal_allocation.sql, sql/50_indicators.sql |
| `cdu` | number | share, 0 to 1 | CDU (P01) share of valid Zweitstimmen, method C. | Landeswahlleiter; sql/20_postal_allocation.sql, sql/50_indicators.sql |
| `contrast` | number | share difference, -1 to 1 | Left-right contrast: (Linke + Grüne) minus (CDU + AfD) share, method C. Describes two ideological camps, not a coalition. | sql/50_indicators.sql |
| `contrast_with_spd` | number | share difference, -1 to 1 | As contrast, with the SPD added to the left camp (Tier 2 variant). | sql/50_indicators.sql |
| `gruene` | number | share, 0 to 1 | Bündnis 90/Die Grünen (P03) share of valid Zweitstimmen, method C. | Landeswahlleiter; sql/20_postal_allocation.sql, sql/50_indicators.sql |
| `linke` | number | share, 0 to 1 | Die Linke (P04) share of valid Zweitstimmen, method C. | Landeswahlleiter; sql/20_postal_allocation.sql, sql/50_indicators.sql |
| `spd` | number | share, 0 to 1 | SPD (P02) share of valid Zweitstimmen, method C. | Landeswahlleiter; sql/20_postal_allocation.sql, sql/50_indicators.sql |
| `turnout` | number | share, 0 to 1 | Voters (station plus allocated postal) divided by eligible voters, method C. | Landeswahlleiter; sql/20_postal_allocation.sql |

## `data/processed/ee_zonal.csv`

Earth Engine zonal statistics per district, zone and indicator (raw.ee_zonal). Lets the pipeline run without Earth Engine credentials (make gee-from-csv).

Primary key: `uwb`, `zone`, `indicator`.

| Column | Type | Unit | Definition | Source |
| --- | --- | --- | --- | --- |
| `uwb` | string |  | Polling-station district number. | Wahlbezirke 2026 |
| `zone` | string |  | Residential land of the district, or the whole district. Values: `residential`, `district`. | src/gee_extract.py |
| `indicator` | string |  | Summer land surface temperature (degrees C) or NDVI. Values: `lst`, `ndvi`. | src/gee_extract.py |
| `mean` | number | degrees C (lst) or dimensionless (ndvi) | Area-weighted mean of the composite over the zone. | src/gee_extract.py |
| `median` | number | as mean | Area-weighted median of the composite over the zone. | src/gee_extract.py |
| `n_eff_pixels` | number | pixels (30 m for lst, 10 m for ndvi) | Effective pixels: the zone's area with valid data divided by the pixel area. | src/gee_extract.py |
| `mean_obs` | number | observations | Mean number of clear observations per pixel in the composite over the zone. | src/gee_extract.py |

## `data/processed/ee_meta.json`

Run metadata of the Earth Engine extraction: run time, earthengine-api version, extent, season, collections and parameters, scene counts per year and clear-observation percentiles. Rendered in docs/provenance.md.

## `data/processed/tier1.csv`

Tier 1 (confirmatory) correlations: partial Spearman rho controlling for log residential density, method C, Holm correction over the 16 tests.

Primary key: `indicator`, `outcome`.

| Column | Type | Unit | Definition | Source |
| --- | --- | --- | --- | --- |
| `indicator` | string |  | Indicator column of the indicators table. | src/analysis.py |
| `outcome` | string |  | Outcome column of the indicators table. | src/analysis.py |
| `n` | integer | districts | Districts with complete data for the pair and the control. | src/analysis.py |
| `rho` | number |  | Partial Spearman rho. | src/analysis.py |
| `ci_low` | number |  | Lower 95 % confidence limit (Fisher transform, Bonett-Wright standard error); assumes independent districts. | src/analysis.py |
| `ci_high` | number |  | Upper 95 % confidence limit. | src/analysis.py |
| `p` | number |  | Two-sided p-value, unadjusted; assumes independent districts, which spatial autocorrelation violates. | src/analysis.py |
| `p_holm` | number |  | Holm-adjusted p-value over the Tier 1 tests. | src/analysis.py |
| `significant` | boolean |  | p_holm below analysis.alpha (0.05). | src/analysis.py |

## `data/processed/tier2.csv`

Primary key: `indicator`, `outcome`, `variant`.

| Column | Type | Unit | Definition | Source |
| --- | --- | --- | --- | --- |
| `indicator` | string |  | Indicator column of the indicators table. | src/analysis.py |
| `outcome` | string |  | Outcome column of the indicators table. | src/analysis.py |
| `variant` | string |  | Robustness variant. | src/analysis.py |
| `tier1_rho` | number |  | The pair's Tier 1 rho, for comparison. | src/analysis.py |
| `n` | integer | districts | Districts with complete data in this variant. | src/analysis.py |
| `rho` | number |  | Spearman rho in this variant (partial on log density, except the raw variant). | src/analysis.py |
| `ci_low` | number |  | Lower 95 % confidence limit. | src/analysis.py |
| `ci_high` | number |  | Upper 95 % confidence limit. | src/analysis.py |
| `p` | number |  | Two-sided p-value, unadjusted. | src/analysis.py |
| `same_sign` | boolean |  | rho has the same sign as tier1_rho. | src/analysis.py |
| `rho_change` | number |  | Absolute difference between rho and tier1_rho. | src/analysis.py |

## `data/processed/moran.csv`

Global Moran's I per variable: queen contiguity, row-standardised, 999 permutations, fixed seed.

Primary key: `variable`.

| Column | Type | Unit | Definition | Source |
| --- | --- | --- | --- | --- |
| `variable` | string |  | Variable of the indicators table. | src/analysis.py |
| `n` | integer | districts | Districts with data. | src/analysis.py |
| `moran_i` | number |  | Global Moran's I. | src/analysis.py |
| `expected_i` | number |  | Expected I without spatial autocorrelation, -1 / (n - 1). | src/analysis.py |
| `p_sim` | number |  | Pseudo p-value from the permutations. | src/analysis.py |
| `islands` | integer | districts | Districts without a contiguous neighbour. | src/analysis.py |
